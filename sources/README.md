# Psychology Source Library

## Upload new sources here

Put new source files in **sources/inbox/**.

Recommended formats: PDF, DOCX, PPTX, TXT / MD, CSV / TSV, JSON.

Example: `Ciccarelli_White_6e_Psychology.pdf`

## Content pipeline

**Source → Extract → Map → Synthesize → Teach → Expert Audit → Serve**

Uploading a source does **not** publish its contents to learners.

The source is treated as evidence. It must first be mapped to the relevant Unit, Topic, Micro-topic Explanation, Quick Learn Card, Active Recall, or Practice/PYQ explanation. New information is added where it improves learning; the same information is not repeated merely because it appears in the source.

## Android upload

On GitHub: open sources/inbox/ → Add file → Upload files → select the source file(s) → commit the upload.

GitHub's browser upload limit is 25 MiB per file; larger files require another Git upload method.

## Important

Source files remain preserved as originals. The website never serves a source simply because it exists in the repository. Provenance and expert-likeness QA remain required.
