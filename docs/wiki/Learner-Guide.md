# Learner Guide

## Purpose

The website is a focused study environment for UGC NET Psychology. Its basic study unit is the **micro-topic**, allowing a learner to work through a large syllabus in small, retrievable units.

## Recommended flow

1. Open **Learn**.
2. Select **Unit → Topic → Micro-topic**.
3. Build an initial mental model.
4. Close the notes and retrieve the idea.
5. Apply the concept to a new situation.
6. Practise with questions.
7. Schedule revision.
8. Return when the item becomes due.

## Micro-topic depth

The current learner experience uses progressive depth:

- **Quick Learn** — central idea and high-value points.
- **Core Learning** — the main mental model.
- **Deep Learning** — comparisons, connections and additional detail.

The goal is not to force every learner through the same amount of reading.

## Retrieval

Retrieval should happen after understanding. Useful prompts ask the learner to reconstruct:

- the definition or central idea;
- important features;
- distinctions from related concepts;
- an explanation without looking at the notes.

Confidence can be used as feedback, but confidence alone is not mastery evidence.

## Practice

Questions are separated into:

- **MCQ** — learning/practice material.
- **PYQ** — previous-year question material when source information is available.

A generated practice question must not be presented as an actual PYQ.

## Revision

The current interface uses four revision ratings:

| Rating | Meaning |
|---|---|
| Again | Recall was unsuccessful. |
| Hard | Recall succeeded with substantial effort. |
| Good | Recall succeeded with normal effort. |
| Easy | Recall was easy. |

Forgetting is treated as feedback about when to return, not as failure.

## Mastery

The learner-facing model is:

**NEW → LEARNING → RETENTION → MASTERED**

Mastery is intended to represent evidence across:

1. Understanding
2. Retrieval
3. Application
4. Delayed retention

Finishing a page therefore should not automatically mean that the concept is mastered.
