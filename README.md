# UGC NET Psychology Study Hub — v6

Based on the uploaded **NET Psychology Syllabus.docx**. The site contains the exact 10-unit syllabus hierarchy plus an expanded study system.

## What v5 adds
- Exam-oriented master notes for every syllabus point.
- **12 micro-topic study lenses per syllabus point** (1000+ total), designed for short teaching/revision sessions.
- Draft practice MCQs and flashcards for every syllabus point.
- A PYQ verification workspace that deliberately avoids inventing or falsely labelling questions as official PYQs.
- Existing dashboard, bookmarks, progress tracking, import/export and editable workspaces.

## Important
The uploaded syllabus does **not** contain previous-year questions. Therefore, v5 does not call generated questions “verified PYQs”. Exact PYQs should be inserted only after checking the original paper or a traceable authoritative reproduction.

## Run
Open `index.html` in a browser. All progress and edits are stored locally in the browser.


## Phone / PWA setup

This version is optimized for Android phones **and tablets** and can be installed like an app when hosted over HTTPS. Tablet layouts support both portrait and landscape orientations.

### Easiest setup
1. Extract this folder.
2. Upload the folder to any static HTTPS host such as Netlify, GitHub Pages, or Vercel.
3. Open the site URL in Chrome on your phone.
4. Use **Install App** / **Add to Home screen**.
5. The site keeps study notes, progress, bookmarks and other workspace data in the browser's local storage. Use **Export backup** regularly before clearing browser data or changing devices.

### Important
The PWA service worker and install prompt require the site to be served over HTTP(S); opening `index.html` directly from a file manager is not the full app experience.
