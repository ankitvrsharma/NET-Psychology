# UGC NET Psychology Study Hub — v10.0

A syllabus-first, micro-topic based study system for UGC NET Psychology.

## v10 revamp
- Redesigned home dashboard focused on the next action rather than navigation overload.
- 10-unit / 440-micro-topic syllabus architecture retained.
- Planner with a six-step learning loop and rapid revision packs for all units.
- Question Lab with unit/search/source filters and hidden-answer retrieval.
- 204 existing PYQ-style practice blocks are explicitly labelled as PYQ-style, not verified past-year questions.
- 435 source/topic MCQ blocks remain available.
- Integrated attached PowerWithin compilation as a source-aligned reference layer without mislabelling it as a PYQ archive.
- Existing spaced repetition, bookmarks, flashcards, dashboard and PWA support retained.

## Important provenance note
The attached PowerWithin PDF describes itself as a NET/JRF/SET preparation compilation and discusses previous-year questions, but the file supplied here is not a standalone archive of verified past-year question papers. The app therefore keeps its question bank clearly separated into PYQ-style and source/topic practice.

## Files
- `index.html` — home / command centre
- `dashboard.html` — mastery and spaced review
- `planner.html` — study operating system and unit packs
- `pyq.html` — question lab
- `unit.html`, `topic.html`, `microtopic.html` — syllabus hierarchy and learning pages
- `practice.html`, `flashcards.html`, `bookmarks.html` — practice utilities
